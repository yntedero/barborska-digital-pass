# ⛏️ Barborská cesta — Digital Pass

> 🥾 193 km · 29 stops · 9 stages — A digital companion for the Barborská cesta pilgrimage trail in central Slovakia.

## ✨ Features

- 🗺️ **Interactive map** — Full trail map with all stops, services & your location
- 📍 **GPS check-in** — Verify your visit at each stop with geolocation
- 📖 **Digital passport** — Track your progress across all 9 stages
- 🏕️ **Trail services** — Find accommodation, food, water & bike repair nearby
- 🌐 **Bilingual** — Slovak 🇸🇰 & English 🇬🇧
- 📊 **Admin dashboard** — Analytics, charts & village reports
- 🌙 **Dark mode** — Comfortable viewing day & night

## 🛠️ Tech Stack

| Layer | Tech |
|-------|------|
| Framework | Nuxt 4 (Vue 3, TypeScript) |
| UI | Nuxt UI + Tailwind CSS 4 |
| State | Pinia |
| Maps | Leaflet |
| Charts | ECharts 6 |
| i18n | @nuxtjs/i18n |

## 🚀 Getting Started

```bash
# Install dependencies
pnpm install

# Start dev server
pnpm dev

# Build for production
pnpm build

# Preview production build
pnpm preview
```

| Command | Description |
